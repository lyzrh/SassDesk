# 角色素材目录

v0.1.0 角色仅使用文本 persona（见 `src/app/characters/types.ts`）。

v0.2.0 桌面悬浮窗启用后，本目录按角色组织素材：

```
assets/characters/
└─ dafeiyu/
   ├─ character.json   # 名称、描述、状态→素材映射、回答风格
   ├─ idle.png
   ├─ listening.png
   ├─ thinking.png
   ├─ working.png
   ├─ success.png
   └─ failure.png
```

素材请使用自制或已获授权的图片；本仓库不提交任何第三方版权素材。
